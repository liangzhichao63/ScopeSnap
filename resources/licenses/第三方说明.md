# 第三方组件与源码

适用版本：ScopeSnap 0.1.0，Windows x64；整理日期：2026-11-04。

本程序使用 Qt 6.5.3 开源版，动态加载 Qt Core、Gui、Widgets、Network 和 Windows 平台插件。随包保留第三方组件的原始许可证及版权声明；本说明不替代这些许可原文。

## Qt

发行包中的 Qt 文件为应用目录下的 `Qt6Core.dll`、`Qt6Gui.dll`、`Qt6Widgets.dll`、`Qt6Network.dll`，以及 `platforms/qwindows.dll`。未修改 Qt 源码，采用 Qt 官方安装包中的 MinGW x64 Release 库。

本项目对上述 Qt 模块采用 LGPLv3 许可选项。许可原文见本目录 `qtbase/LICENSES/`；Qt 所含第三方代码另按各自许可，归属与原文见 `qtbase/` 中保留的原始路径和 `Qt第三方归属索引.md`。该目录保留了 qtbase 源码的第三方归属集合，其中部分组件仅用于其他平台、工具或未启用功能，不表示全部编入本程序。

本程序的 Qt 图形组件使用 FreeType 来源代码，选择 FreeType License（FTL）许可选项。Portions of this software are copyright © 2023 The FreeType Project (www.freetype.org). All rights reserved. 许可原文见 `qtbase/src/3rdparty/freetype/LICENSE.txt`；其他第三方组件按归属索引保留原始声明。

完整、未经修改的 Qtbase 6.5.3 源码随总发行包提供，位置为 [源码/Qt/qtbase-everywhere-src-6.5.3.tar.xz](../源码/Qt/qtbase-everywhere-src-6.5.3.tar.xz)。该目录同时包含官方 SHA-256 文件及下载核验说明。不要在对外分发时移除源码目录、许可证或归属说明。源码包含构建文件、Qtbase 内含的第三方源码及其许可证。

使用者可以修改、重新构建并替换这些 Qt 库，且可以为调试这些修改而逆向分析本应用；本包不施加阻止替换、重链接或运行修改版 Qt 的签名校验。操作方法：

1. 关闭 ScopeSnap，备份原有 Qt DLL 与 `platforms/qwindows.dll`。
2. 解压随附 Qtbase 源码，参考其中 `README.md` 和 `configure` 构建。原包是 x86_64、shared、Release、MinGW GCC 11.2 工具链；本目录 `qtbase-build/qconfig.pri` 保存安装版配置摘要。
3. 使用相同架构、兼容编译器及 ABI 构建修改后的共享库。将四个 Qt DLL 替换到 EXE 同目录，将相匹配的 `qwindows.dll` 替换到 `platforms/`。保留目录结构，避免混用 Debug/Release 或不同编译器的库。
4. 启动程序验证。需要重新构建应用时，使用 [随附项目源码](../源码/ScopeSnap/) 及其构建说明；Qt 的构建工具、插件和库需要版本匹配。

## MinGW 运行库

随程序提供 `libgcc_s_seh-1.dll`、`libstdc++-6.dll` 和 `libwinpthread-1.dll`。它们来自 Qt 安装器配套的 MinGW GCC 11.2.0（x86_64-posix-seh-rev3，MinGW-w64 runtime v9）。原始构建记录及许可证保存在 `mingw-runtime/`。

- GCC/libstdc++：GPLv3 加 GCC Runtime Library Exception 3.1，见 `mingw-runtime/gcc/COPYING3` 和 `COPYING.RUNTIME`。本程序经常规 GCC 编译，未使用会改变 GCC 中间表示的专有编译插件；这些运行库作为本应用组合的必要组成随包提供，依据运行库例外处理独立应用代码的许可，不把运行库当作独立通用 SDK 再发行。
- winpthreads：其 MIT 风格许可及其中 Lockless 来源部分的 BSD 条款见 `mingw-runtime/winpthreads/COPYING`。
- MinGW-w64：相关版权、公有领域说明及许可见 `mingw-runtime/mingw-w64/`。保留这些原文，不以本应用的许可替换。

GCC 运行库例外不意味着所有 GCC 代码都不受 GPL 约束。若以后修改运行库、另行独立发布运行库或改变编译方式，应重新核对该变更对应的源代码提供义务。

## 驱动与本项目源码

VISA 驱动不是上述 Qt/MinGW 开源组件。本程序仅按需加载用户电脑已安装的 VISA 运行库，不自行修改驱动绑定，也不把 NI-VISA 等供应商软件标为开源软件。若总发行包另附供应商的官方驱动安装器，应保持其独立目录、原始安装器和许可；其来源、完整性和安装要求以总包的驱动说明为准。本文件不授予这些驱动的再分发权，安装和使用仍适用供应商自己的许可。

本项目自有源代码自 2026-11-05 起采用 MIT 许可证，原文见源码仓库根目录的 `LICENSE`；新的便携包同时在根目录及 `源码/ScopeSnap/LICENSE` 保留该文件。MIT 许可适用于自有代码，不替代 Qt、MinGW、NI 或其他第三方组件各自的许可与版权声明。
